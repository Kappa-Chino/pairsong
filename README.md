# ふたり音 Frontend

Leafonyから取得したGPSルートを登録し、生成された音楽のQRコード、再生画面、SABAEMapを表示するVue 3アプリです。

## 開発環境の準備

```sh
npm install
```

## 開発サーバー

```sh
npm run dev
```

PowerShellの実行ポリシーで`npm`がブロックされる場合：

```powershell
npm.cmd run dev
```

## Production build

```sh
npm run build
```

公開パスは`/futari_ne/`に設定されています。
